# Piano SoundFonts

PokeyTracker's **Piano sound** (on the Arrangement window) plays a song's notes on a sampled
piano instead of the POKEY chip. The piano is a SoundFont: put one `.sf2` file in this folder
and PokeyTracker uses it. The first `.sf2` here, by name, is the one loaded.

The files are not in the repository (`*.sf2` is ignored): they are tens of megabytes and each
comes under its own licence.

## The one used while building it

**YDP Grand Piano** (`YDP-GrandPiano-20160804.sf2`), from the FreePats project:
<https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html>

- Built from the Zenph Studios Yamaha Disklavier Pro piano multisamples for OLPC; the
  SoundFont was produced by Roberto Gordo Sáez for FreePats.
- Licence: **Creative Commons Attribution 3.0** - free to use and redistribute, including
  commercially, **as long as the author and source are credited**. Anything that ships it -
  an installer, a sold app - must carry that credit, for instance in an About box.

## Others from the same page

- **Upright Piano KW** - CC0 (public domain, no credit needed). Ships as `.7z`.
- **Salamander Grand Piano** (Alexander Holm) - CC-BY 3.0, higher quality, about 300 MB as SF2.

Check the licence on the download page before shipping any of them.
